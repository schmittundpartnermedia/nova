# Ketten-Abnahme (Vision)

## Definition fertig

Eine Fähigkeit ist **nur** funktional, wenn die komplette Kette in der echten NOVA.app gilt:

1. Verstehen
2. Fehlende Infos nachfragen (Slots)
3. Auftrag im Arbeitsgedächtnis (ActiveWork) halten
4. Ausführen
5. Verifizieren (Evidence)
6. Erst dann „erledigt“

Punktchecks in `abnahme-matrix.md` sind **keine** Vision-Abnahme.

## Status

| Kette | Schritte | Status |
|---|---|---|
| Arbeitsgedächtnis ActiveWork | Create → Continue → Slot-Fill → Cancel | TEIL (Fundament live) |
| Mail | Absender → Entwurf → Freigabe → SEND_VERIFIED | TEIL (via ActiveWork) |
| Tickets | Titel/Details klären → anlegen → belegt | TEIL (ActiveWork) |
| Kontakte | Name/Mail klären → anlegen → belegt | OFFEN |
| Projekte | Name klären → anlegen → belegt | TEIL (ActiveWork) |
| Kalender lokal | Wann/Was klären → anlegen → belegt | TEIL (ActiveWork-Kette) |
| Watch | Lage → Handlung vorschlagen → ggf. ausführen | OFFEN |
| Computer/Mac | Mehrschritt öffnen→UI→prüfen | OFFEN |
| Coding | Path-Slot → Cursor → Verify | OFFEN |
| Stimme live | Mic → Auftrag → TTS | OFFEN |
| Wissen/Recherche | Frage halten → Evidence → Antwort | OFFEN |
| Verify-Gate | DONE nur mit Evidence | OFFEN |

## Regel

Keine nächste Domain, solange die aktuelle Kette in NOVA.app nicht 100% grün ist.
